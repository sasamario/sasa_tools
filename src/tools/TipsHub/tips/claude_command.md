---
title: "Claude Codeコマンド一覧"
description: "Claude Codeで使用可能なコマンドとその詳細"
tags: ["Claude"]
---

| コマンド | 詳細 | 利用ケース |
|---|---|---|
| `/context` | 現在のコンテキストウィンドウがどれくらい埋まっているか確認できる | 長いタスクや複数ファイルを扱う前に、容量に余裕があるか確認したいとき |
| `/compact` | 古いメッセージを要約して会話履歴のサイズを縮小する | セッションが長くなり応答の質が落ちてきたと感じたとき |
| `/clear` | 会話履歴をクリアしてコンテキストを解放する(エイリアス: /reset, /new) | 別のタスクに切り替えたいとき、前の話題が不要なとき |
| `/resume` | 過去のセッションを再開する | 昨日の続きから作業したいとき |
| `/branch` | 現在の会話をコピーして新しいブランチを作る(旧 /fork) | 別のアプローチを試したいが、今までの流れも残しておきたいとき |
| `/diff` | 変更内容を確認する | コミット前にどのファイルがどう変わったか確認したいとき |
| `/cost` | セッションのコストを確認する(/usage のエイリアス) | トークン消費量や料金を把握しておきたいとき |
| `/model` | 使用するモデルを切り替える | タスクの難易度に応じて軽量モデル/高性能モデルを使い分けたいとき |
| `/init` | プロジェクトに CLAUDE.md ガイドを初期化する | 新しいプロジェクトでClaude Codeを使い始めるとき |
| `/mcp` | MCPサーバー接続とOAuth認証を管理する | 外部ツール(GitHub、Slackなど)と連携させたいとき |
